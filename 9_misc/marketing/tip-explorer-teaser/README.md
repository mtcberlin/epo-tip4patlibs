# TIP Explorer teaser

One self-playing 16:9 slide that introduces the TIP Explorer (`2_patstat_explorer/`). Made for
Jens Hoheisel's five minutes at the PATLIB "Shaping the Future" session on 10 November 2026.

| File | What |
|---|---|
| `tip-explorer-teaser.mp4` | The slide as a 21.6 s loop, 1920×1080. In PowerPoint: insert on a blank slide, full size, Playback → Start automatically, Loop until stopped |
| `tip-explorer-teaser-still.png` | A still of the same slide, for print or as a fallback |
| `tip-explorer-teaser.html` | The source: open it in a browser to see it play |
| `shots/` | The six screens, taken from `2_patstat_explorer/3_explorer-documentation.pdf` |
| `build.sh` | Renders the HTML into the MP4 and the still (headless Chromium + ffmpeg) |

Every figure on the slide is read off the screenshot it sits on (PATSTAT Global, Autumn 2025).
The TIP Explorer is Arne Krüger's own work; the slide credits depa.tech / piznet.
